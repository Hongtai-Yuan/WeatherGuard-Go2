# 项目贡献描述

- 基于 PPO 训练 Unitree Go2 低摩擦速度跟踪型 locomotion policy，设计线速度/角速度跟踪、机体姿态稳定、关节能耗、动作平滑、足端打滑抑制、步态相位约束等奖励项，使策略能够在不同摩擦系数地面上学习稳定行走；随后将训练得到的 ONNX policy 迁移到 Isaac Sim / Isaac Lab，并对齐 observation、action、PD 控制参数和系统辨识后的动力学参数，完成低摩擦运动控制的 sim2sim 验证。

- 构建恶劣天气下 LiDAR 感知退化与地面湿滑耦合仿真，将雾天点云退化模型接入 Isaac 实时 LiDAR 流程，模拟强度衰减、后向散射、点云稀疏化、距离噪声和虚假回波；同时根据天气严重程度调整地面摩擦系数，使机器人在浓雾、湿滑地面等场景下同时面临感知不确定性和运动稳定性下降的问题。

- 基于退化后的 3D 点云生成局部高程图，并利用局部栅格内高度方差、点云数量和空间一致性估计观测置信度，构建 confidence-aware costmap：高置信度障碍保留较强避障代价，低置信度异常点或伪障碍降低代价影响，从而减少雾天点云噪声导致的误占据、急停和路径震荡，并接入 ROS2 / Nav2 实现 Go2 目标点导航验证。
